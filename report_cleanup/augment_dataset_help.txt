usage: augment_dataset.py [-h] [--image-dir IMAGE_DIR] [--workbook WORKBOOK]
                          [--output-dir OUTPUT_DIR] [--output-csv OUTPUT_CSV]
                          [--report REPORT] [--codex-report CODEX_REPORT]
                          [--contact-sheet CONTACT_SHEET] [--copies COPIES]
                          [--seed SEED] [--workers WORKERS]
                          [--filename-column FILENAME_COLUMN]
                          [--label-column LABEL_COLUMN]
                          [--specimen-column SPECIMEN_COLUMN] [--overwrite]

Create an offline corrosion-classification dataset containing each readable
original plus reproducible augmented copies.

options:
  -h, --help            show this help message and exit
  --image-dir IMAGE_DIR
  --workbook WORKBOOK
  --output-dir OUTPUT_DIR
  --output-csv OUTPUT_CSV
  --report REPORT
  --codex-report CODEX_REPORT
  --contact-sheet CONTACT_SHEET
  --copies COPIES       Augmented copies per readable source image (default:
                        4; 5x total).
  --seed SEED
  --workers WORKERS     Parallel image workers (default: up to 4).
  --filename-column FILENAME_COLUMN
  --label-column LABEL_COLUMN
  --specimen-column SPECIMEN_COLUMN
  --overwrite           Replace existing generated outputs.
