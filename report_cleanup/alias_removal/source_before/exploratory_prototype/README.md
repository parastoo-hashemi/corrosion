# Exploratory corrosion prototype

Early image-processing, random-forest and simulated-trajectory experiments. This
phase does not provide a defensible held-out benchmark. Saved exploratory artifacts
remain under [ressult/](ressult/), retaining their original spelling and contents.

Former folder: `main_first/`. That root path is now a compatibility link to this
directory. Many scripts execute work at import time; inspect them before running.
