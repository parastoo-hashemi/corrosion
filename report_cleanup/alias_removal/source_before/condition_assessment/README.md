# Historical interpretable condition-assessment pipeline

Interpretable corrosion features, structural feasibility, degradation and first proxy-RUL analysis. Saved results use the older 792-row/five-class basis. CSV/parquet/models are in `outputs/`; generation-specific reports are in `reports/`.

Current modelling source has unresolved execution/configuration defects. Do not
interpret a saved output as proof that the present code can reproduce it.
