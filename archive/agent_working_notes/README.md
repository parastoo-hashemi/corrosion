# Historical development records

This archive preserves original plans, task prompts, meeting narratives, manuscript
reviews, evidence/QA records and superseded entry guides. **Start with the current
[root README](../../README.md) and [curated docs](../../docs/project_history.md).**
Archived text is historical evidence, not an instruction to execute and not the
current scientific interpretation. Some records contain obsolete proposals,
absolute paths from earlier checkouts, or generation-specific results.

Paths mirror their original repository locations. For example, this archive's
`main_4/` contains former main_4 Markdown records, not a relocated modelling package.
Interpret original relative references from their original repository context;
use the [move manifest](../../report_cleanup/move_manifest.csv) to find relocated
records. Existing absolute links in historical prose were not silently rewritten.

`report_v2/evidence/`, `report_v2/qa/`, `report_v2/critique/` and `activity_report/notes/`
are physically archived here, with relative symbolic links at their original paths.
Other links are retained where immutable scripts, report sources or manifests need
them. Preserve those links when copying. The archived text and scientific outputs
are byte-identical to their pre-cleanup originals.

The previously staged deletion of `activity_report/CODEX_AUTONOMOUS_PROMPT.md` was
respected; its content was recovered here from the starting Git commit. No file
was discarded as obsolete solely because an agent wrote it.
