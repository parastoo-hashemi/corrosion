\section{Feature and computation contract}
The focused capacity metadata list contains campaign, series, treatment group, treatment protocol, coarse treatment, coarse treatment label, mesh count, chloride concentration, cover, observation week, and ageing days. These are 11 input columns before encoding, not necessarily 11 dimensions after one-hot encoding. RGB and HSV families contain 41 and 36 input columns, respectively. The combined metadata+RGB+HSV input contains 88 columns before encoding. These counts are taken from the saved feature-family comparison, not inferred from the number of displayed importances.

The image-only names in that experiment refer to derived RGB/HSV families with the manually assigned visible targets excluded. The earlier mixed structural representation does include recorded visible labels. These input contracts prevent the phrase ``image-based structural model'' from erasing materially different information sources.

Saved configurations specify a random seed of 42 for the focused experiments, two repetitions of five folds, and mesh stratification in the pooled case. The original model families include tree ensembles and Ridge. Some numeric configuration fields are currently corrupted, so this appendix does not silently substitute guessed historical hyperparameter values. The saved results and exact current files are hashed in the verification tables. Historical training duration and complete environment metadata are not consistently available; the report does not invent them.

\section{Current software defects and chronology}
PyYAML parses the unquoted value \texttt{NO} as boolean false for ten no-treatment specimens. The saved coarse-treatment field contains the string \texttt{False} for 168 rows, while the raw treatment field retains \texttt{NO}. The report uses intended treatment semantics when describing the experiment, without modifying the historical modelling artifacts.

The substitution pattern involving \texttt{main\_first} is present in \path{main}, \path{main_2}, \path{main_3}, and \path{main_4}; a scan of the augmentation source finds no such instance. Examples include a corrupted pandas aggregation name and invalid YAML numeric values. Their root cause is not established here. The cited saved scientific output artifacts checked in the rebuild predate the earliest affected source timestamp. This observation supports separation of saved results from currently broken code but is not proof of an exact executable history.

The mapping file is itself later than some saved outputs and contains affected narrative fields. Its campaign/design fields used here remain intact and agree with the saved aligned table. The independent augmentation work is later still and is checked separately. Archive exports and the older snapshot are not treated as additional experiments merely because a copy exists.

\section{Reproduction commands and boundary}
From the repository root, the following commands verify saved outputs and regenerate the report's figures and tables without fitting a model:
\begin{quote}\small\ttfamily
python report\_v2/scripts/audit\_evidence.py\\
python report\_v2/scripts/make\_figures.py
\end{quote}
The project scientific environment provides pandas, NumPy, SciPy, PyYAML, matplotlib, and Pillow. The audit checks image readability in the ZIP archive, terminal-label counts, paired prediction errors, summary aggregation, split disjointness, and source timestamps. It writes a machine-readable claim record and source hashes.

Compile from this document's directory using:
\begin{quote}\small\ttfamily
latexmk -pdf -interaction=nonstopmode\\
\hspace*{1em}-halt-on-error thesis.tex
\end{quote}
The displayed command is one shell command, split here for readability. The IEEE article uses the analogous command with \texttt{article.tex}. BibTeX reads the shared bibliography. The rebuild script compiles every version and rejects unresolved references or citations. Original source and frozen-report hashes are checked separately from compilation.

These steps reproduce the reported presentation and aggregation. Reproducing historical training would require resolving the software defects and reconstructing missing environment details, and was deliberately outside the report rebuild. The references that follow support background and experimental attribution; the source map above supports the repository-specific empirical results.
